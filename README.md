## 公開先と復元について

本番の公開先はCloudflareです。このリポジトリの更新はバックアップ目的です。検索向けcanonicalもCloudflareのURLを維持しています。

404ページもCloudflare公開版と同一です。GitHub Pages向けのサブディレクトリ調整はしていません。GitHub Pagesの設定変更は行っていません。

復元する際は、既存のCloudflareプロジェクトの設定を確認して公開データを配置してください。現在の設定はWorker名 `kanamo-nail`、静的アセット `./public`、`assets.not_found_handling` は `404-page` です。ルートのREADMEや旧版画像などのバックアップ専用ファイルを、そのまま公開用ディレクトリへ混ぜないでください。

このリポジトリは公開用ファイルのバックアップです。カタログ生成元、作業記録、認証情報は含めていません。
