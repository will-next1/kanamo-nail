公開版がCloudflareで100%配信されていることを確認しました。同期対象の配信ファイルを本番から取得して照合し、バックアップの公開用全1,110ファイルが公開時のSHA-256記録と一致することを確認しています。_headersは公開時のローカル記録と照合しています。

公開後に3コースのPC幅1280px・スマホ幅375pxで、おすすめ表示、写真一覧への移動、相談チャットの予約案内とオフ料金を確認しました。実機とSafariは未確認です。

## 復元について

本番の公開先はCloudflareです。このリポジトリは公開用ファイルのバックアップとして使用します。

以前の画像等、バックアップ側にのみ存在するファイルは残しています。復元時は公開対象を確認し、READMEや旧版画像などのバックアップ専用ファイルを公開用ディレクトリへ混ぜないでください。過去の状態はGitのコミット履歴から確認できます。

既存Cloudflare設定はWorker名 kanamo-nail、静的アセット ./public、assets.not_found_handling は 404-page です。canonical URLはCloudflareを指します。404ページもCloudflare用の内容です。

カタログ生成元、作業記録、認証情報はこのバックアップに含めていません。
